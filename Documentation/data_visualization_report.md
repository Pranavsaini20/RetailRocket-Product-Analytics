# Power BI Data Visualization Report

## Page 1 — Executive Overview
Headline KPIs for users, products, events, transactions, conversion, cart abandonment and average events per user. Supporting visuals cover activity over time, event mix, category activity, funnel stages and product availability.

## Page 2 — User Analytics
Viewing, add-to-cart and purchasing users; user purchase rate; user activity; funnel and category engagement.

## Page 3 — Product Analytics
Product availability, average views per product, the project's purchase-rate measure, top viewed/purchased products and category comparisons.

## Page 4 — Executive Insights
Business summary, selected KPIs, key findings and recommendations.

## Visual principles
- KPI cards for headline measures.
- Line charts for trends over time.
- Bar charts for product/category comparisons and rankings.
- Funnel-style visuals for behavioral stages.
- Consistent titles and formatting.
- Insight text to connect the data to possible actions.

Visual patterns do not prove causation. Validate definitions and investigate segments before acting.
