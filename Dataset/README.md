# Dataset Notes

## Source
RetailRocket e-commerce recommender-system dataset. Retain attribution to the original source when redistributing data.

## Files used
- `events.csv`: visitor event records.
- `item_properties_part1.csv`: first portion of timestamped item properties.
- `item_properties_part2.csv`: second portion of timestamped item properties.
- `category_tree.csv`: category hierarchy.

The current imported Events table contains approximately 2.76 million rows; the combined item-property sources contain more than 20 million records. Exact counts can vary by source version and import completeness.

## Repository policy
Raw CSVs are not included in this documentation pack because they are large and GitHub has file-size limits. Link to the original dataset or include a small permitted sample if appropriate. Do not redistribute data without permission.
