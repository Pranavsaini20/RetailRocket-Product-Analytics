# Dataset Information

This project uses the RetailRocket e-commerce behavior dataset.

## Dataset Components
- Events: user interactions such as views, add-to-cart events, and transactions
- Item Properties: product attributes, including category and availability information
- Category Tree: relationships between product categories

The dataset supports analysis of user engagement, conversion behavior, product performance, and customer purchasing patterns.

Dataset source: RetailRocket dataset on Kaggle.
